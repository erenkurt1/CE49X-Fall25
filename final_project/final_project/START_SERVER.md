# Quick Start: Run Server Independently

## ✅ The Server Runs Completely On Its Own!

Once started, you don't need me (or any AI assistant) - it runs independently on your computer.

---

## Quick Start (3 Steps)

### 1. Start Docker (if needed)
```bash
docker-compose up -d
```

### 2. Start Server

**Option A: Double-click** `start_server.bat`

**Option B: Command line**
```bash
python scripts\view_articles_hybrid_llm.py
```

### 3. Use It!
- Browser opens automatically at: http://localhost:8002
- Or go there manually
- Use Chat, QA, Search, etc. - all work independently!

---

## To Stop Server

Press **Ctrl+C** in the terminal

---

## That's It! 

The server runs completely independently. You can:
- ✅ Close this chat
- ✅ Close your IDE  
- ✅ Close everything
- ✅ Server keeps running!

Just use http://localhost:8002 whenever you want! 🚀
