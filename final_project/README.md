## Project Structure

```
final_project/
├── data/
│   ├── raw/           # Raw scraped/collected data
│   └── processed/     # Cleaned data (for Task 2)

```

## Task 1: Data Collection

See `../Task1_Data_Collection_Pathway.md` for detailed implementation pathway.

### Quick Start

1. Create virtual environment:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run data collection:
   ```bash
   python scripts/newsapi_collector.py
   ```
